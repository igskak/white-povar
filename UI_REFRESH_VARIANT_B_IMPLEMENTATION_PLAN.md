Не менять опубликованное `brand.font` на `grotesque`, не отключать font setting и не переопределять все шрифты приложения. ## 7. Поведение: решения до сборки интерфейса

### Поиск и быстрые фильтры

- Поиск на главной должен работать на реальном каталоге через существующий provider/repository. При запросе/фильтрах показать результаты в месте каталога и убрать крупный showcase/авторский блок, как в B; после сброса восстановить обычную главную.
- Не фильтровать только уже загруженные первые девять/двадцать рецептов с видом полного каталога. Сохранить существующие pagination/загрузку/отмену устаревших запросов; не обещать total count, если API его не даёт.
- `До 30 хв` — структурированный `maxTime`; `Без м’яса` — `DietFilter.noMeat`, неизвестная диета не подходит. `Сніданки` — реальная category, не поиск подстроки в названии.
- В текущем `SearchFilters` нет free-only facet. Не переносить чип «Безкоштовні» как фиктивный фильтр. В этой итерации убрать его, если действующий API/repository не поддерживает корректную выборку всего каталога по этому признаку; не расширять backend только ради чипа.
- Сохранить независимость Home и Search: не оставлять неожиданное состояние общего notifier после ухода. Выбрать простой существующий способ владения/сброса состояния, без второго search engine.
- Loading/error/empty: явная обратная связь, повтор запроса и сброс фильтров. Сохранять введённый запрос при ошибке. Проверить быстрый ввод и смену фильтра во время загрузки.

### Порции и ингредиенты

- Одно состояние выбранных порций на открытую страницу, исходно `recipe.servings`; сбрасывать при смене recipe ID. Не мутировать cached Recipe и исходный список ингредиентов.
- Количество = исходное количество × выбранные порции / исходные порции. Защитить нулевую/некорректную базу; не показывать NaN/Infinity. Ограничения выбрать по реальным контрактам сервисов, не копировать демо-диапазон 1–20.
- Форматировать украинские десятичные значения без хвоста `2.0` и артефактов double; небольшое количество не должно превращаться в бессмысленный ноль. Не конвертировать единицы измерения без отдельной задачи. `notes` и свободный текст вроде «за смаком» сохранять.
- Чекбоксы означают локальную отметку в списке рецепта, а не фактическое наличие продукта в pantry. Не делать сетевую запись при отметке; состояние достаточно держать в рамках открытой страницы. Не прибавлять эти отметки к прогрессу готовки.
- `onAddToShopping` и `onAddToPlan` сейчас передают `recipe.servings`: переключить на выбранное значение. Заблокировать повторный submit во время операции, показать успех только после успешного ответа, обработать ошибку.
- Проверить, нужен ли выбранный serving count существующему cooking flow. Если там отображаются количества, передавать его согласованно через текущую модель/маршрут без потери resume. Не создавать отдельное хранилище прогресса.

### Доступы и действия

- Решение о доступе — серверная проекция `recipe.isLocked`, как в текущем коде. Не заменять её локальным `isPremiumProvider`: бывают бесплатные previews и отдельные покупки коллекций.
